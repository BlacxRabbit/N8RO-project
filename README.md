# N8RO Assignment Project

This repository contains the N8RO custom human animation assignment project.

Project folder:

```text
sim-student-human-animations/
```

The project includes:

- Custom C++ N8RO animation plugin source code
- Built plugin DLL
- Lua mission script that cycles animation states
- Nathan human GLB model used in the screen capture
- Submission email draft with the required written description

See `sim-student-human-animations/README.md` for build, install, and submission details.
